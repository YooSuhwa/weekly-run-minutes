# Socrates 질문 목록 (Q0~Q21)

## Q0: 슬랙 웹훅 설정 (선택 사항)

**Q1 시작 전에 반드시 슬랙 웹훅 URL을 질문합니다.**

```json
{
  "questions": [{
    "question": "기획 진행 상황을 슬랙으로 알림 받으시겠어요?\n\n슬랙 웹훅 URL을 입력하시면 주요 단계별로 알림을 보내드립니다.\n(선택 사항 - 필요 없으시면 '건너뛰기'를 선택하세요)",
    "header": "슬랙 알림",
    "options": [
      {"label": "건너뛰기", "description": "슬랙 알림 없이 진행"},
      {"label": "웹훅 URL 입력", "description": "Other를 선택하여 URL 직접 입력"}
    ],
    "multiSelect": false
  }]
}
```

**처리 규칙:**
- "건너뛰기" 선택 → `SLACK_WEBHOOK_URL = null` (알림 비활성화)
- Other로 URL 입력 → `SLACK_WEBHOOK_URL = {입력값}` (알림 활성화)

**⚠️ 중요:** 사용자가 URL을 제공하지 않으면 슬랙 알림 기능은 완전히 비활성화됩니다.
하드코딩된 웹훅 URL을 절대 사용하지 마세요!

**모든 질문은 반드시 AskUserQuestion 도구를 사용합니다.**

## 세렌디피티 기능 (Q7 완료 후)

**Q7 완료 직후**, 8개 도메인 중 1개를 랜덤 선택하여 창의적 연결을 제안합니다.

### 8가지 연결 도메인

| # | 도메인 | 핵심 관점 | 예시 연결 |
|---|--------|----------|----------|
| 1 | 역사 | 과거의 유사 사례 | 가계부 → 조선시대 장책 |
| 2 | 산업 | 다른 산업의 성공 모델 | 학습 앱 → 게임의 레벨업 시스템 |
| 3 | 인문학 | 인간 본성, 철학 | 다이어트 앱 → 의지력의 한계(넛지 이론) |
| 4 | 트렌드 | 최신 기술/사회 트렌드 | 쇼핑몰 → 라이브 커머스 |
| 5 | 과학 | 과학적 원리, 자연 영감 | 추천 알고리즘 → 개미의 페로몬 경로 |
| 6 | 예술 | 미학, 감각적 경험 | 명상 앱 → 마크 로스코의 색면 추상화 |
| 7 | 문학 | 스토리텔링, 서사 구조 | 다이어트 앱 → 영웅의 여정 |
| 8 | 음악 | 리듬, 조화, 감정적 공명 | 운동 앱 → EDM의 빌드업과 드롭 |

### AskUserQuestion 형식

```json
{
  "questions": [{
    "question": "잠깐, 재미있는 아이디어가 떠올랐어요!\n\n당신의 '{프로젝트명}'을 '{선택된 도메인}'의 관점에서 생각해보면 어떨까요?\n\n{도메인별 연결 프롬프트}\n\n이 관점에서 떠오르는 아이디어가 있으신가요?",
    "header": "창의적 연결",
    "options": [
      {"label": "흥미로워요!", "description": "이 관점에서 아이디어를 더 탐구"},
      {"label": "다른 분야로", "description": "다른 분야의 관점이 궁금해요"},
      {"label": "건너뛰기", "description": "원래 질문으로 돌아가기"}
    ],
    "multiSelect": false
  }]
}
```

### 응답 처리

| 사용자 응답 | 처리 |
|------------|------|
| "흥미로워요!" | 해당 도메인 심화 질문 1개 후 Q8로 |
| "다른 분야로" | 다른 도메인 1개 랜덤 제안 (최대 1회만) |
| "건너뛰기" | 바로 Q8로 진행 |
| Other (직접 입력) | 사용자 아이디어 기록 후 Q8로 |

### 결과 기록

세렌디피티 응답은 PRD 생성 시 "창의적 영감" 섹션에 포함됩니다.

## 기술 스택 질문 (Q19~Q21)

Q18 완료 후, AI가 지금까지의 답변을 종합 분석하여 기술 스택을 추천합니다.

| Q | 질문 | AI 추천 방식 |
|---|------|-------------|
| Q19/21 | **백엔드 프레임워크**를 선택해주세요. | AI가 프로젝트 특성 분석 후 추천 (이유 포함) |

1. AI가 Q1~Q18 답변을 종합 분석
2. 프로젝트 특성에 맞는 기술 스택 추천 (이유 포함)
3. 사용자가 AI 추천 수락 또는 직접 선택

### 추천 예시:

```
지금까지 답변을 분석한 결과, 당신의 프로젝트에 맞는 기술 스택을 추천드립니다.

        자동 API 문서 생성, 비동기 지원

선택지:
1. FastAPI (Python) - AI 추천
2. Django (Python) - 풀스택, 관리자 페이지 자동 생성
```

## TDD 기반 개발 안내 (Q21 완료 후)

Q21 완료 후, 다음 안내 메시지를 표시합니다:

```
기술 스택 선택이 완료되었습니다!

이제 AI 코딩 파트너가 다음 방식으로 개발을 진행합니다:

Contract-First TDD (계약 우선 개발)

1. Phase 0: 계약 & 테스트 설계
   - 모든 API 계약을 먼저 정의
   - 테스트 케이스 선행 작성 (RED 상태)
   - Mock API 생성 (프론트엔드 독립 개발용)

2. Phase 1+: 병렬 구현
   - 백엔드: 테스트 통과 목표로 구현 (RED→GREEN)
   - 프론트엔드: Mock API로 독립 개발 (RED→GREEN)

3. 통합 검증
   - Mock 제거 → 실제 API 연동
   - E2E 테스트로 전체 흐름 검증

이 방식의 장점:
- BE/FE가 서로 기다리지 않고 병렬 개발 가능
- "테스트 통과 = 완료"라는 명확한 기준
- 통합 시 충돌 최소화

이제 7개의 기획 문서를 생성하겠습니다.
문서에는 TDD 워크플로우가 반영됩니다.
```
