# PRD Interview Skill

## 목적

이미 작성된 PRD를 기반으로 **불명확하거나 깊이 있는 논의가 필요한 부분**을 발견하고,
사용자와의 인터뷰를 통해 PRD를 보완한다.

---

## 발동 조건

다음과 같은 요청 시 발동:
- "PRD 검토해줘"
- "기획서 읽고 질문해줘"
- "PRD 인터뷰 시작"

---

## 워크플로우

### Phase 0: 문서 읽기
```
1. docs/PRD_MAP.md 읽기
2. docs/AI_EXECUTION_PRINCIPLES.md 읽기
3. docs/PRD_WeeklyRun_v0.11.md 읽기
4. docs/DEVELOPMENT_METHODOLOGY.md 읽기
```

### Phase 1: 심층 인터뷰

**AskUserQuestion 도구를 사용하여 질문**

질문 영역:
- 기술적 구현 (Technical Implementation)
- UI/UX 디테일
- 엣지 케이스 및 예외 처리
- 트레이드오프 및 우선순위
- 불명확하거나 모호한 부분

**질문 규칙:**
- 뻔한 질문 금지 (PRD에 명시된 내용 재확인 X)
- 한 번에 1~2개 질문
- 사용자 답변 후 후속 질문으로 깊이 파고들기
- 모든 궁금증이 해소될 때까지 계속 질문

### Phase 2: 완료

모든 인터뷰 완료 후:
1. 인터뷰 내용 요약
2. PRD 보완이 필요한 부분 제안 (선택적)
3. "다음 단계로 넘어가자"라고 하면 종료

---

## 질문 예시 (참고용)

| 영역 | 질문 예시 |
|------|----------|
| 기술 | "STT Provider 추상화에서 Web Speech API 외에 fallback은 어떻게 처리할 계획이야?" |
| UI/UX | "회의 중 발표자가 순서를 건너뛰고 싶을 때 UX는 어떻게 되어야 해?" |
| 엣지케이스 | "녹음 파일이 2시간 이상일 때 STT 처리 전략은?" |
| 트레이드오프 | "P1-lite에서 Confluence 업로드 실패 시, 재시도 vs 로컬 저장 중 우선순위는?" |
| 모호함 | "주간업무록 파싱에서 '상세업무'의 depth가 3단계 이상이면 어떻게 처리해?" |

---

## 인터뷰 시작 메시지
```
PRD 문서들을 모두 읽었습니다.

이제 불명확하거나 깊이 있는 논의가 필요한 부분에 대해 질문할게요.
뻔한 질문은 하지 않을 거예요.

모든 궁금증이 해소될 때까지 계속 질문하고,
완료되면 "다음 단계로 넘어가자"라고 말씀해 주세요.

그럼 시작합니다!
```

---

## 완료 조건

- 사용자가 "다음 단계로 넘어가자" 또는 유사 표현
- 또는 AI가 더 이상 질문할 내용이 없다고 판단
