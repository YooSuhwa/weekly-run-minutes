주간보고는 업무 현황을 빠르고 명확하게 파악할 수 있도록 텍스트 링크와 계층형 구조를 사용하여 작성합니다. 아래 규칙을 준수하여 작성해 주시기 바랍니다.

## 1. 작성 원칙
- 텍스트 링크 사용: 업무 카드(미리보기)가 아닌, 텍스트에 하이퍼링크를 입힌 형태로 작성합니다.
- 계층 구조 준수: **[대분류] > [소분류] > [상세내용]**의 3단계를 들여쓰기로 명확히 구분합니다.
- 상태 표기: 소분류(단위 업무) 앞머리에 업무 상태를 표기합니다.

## 2. 상세 작성 규칙
### 2.1. 계층별 작성법
- 1단계 (대분류): 주요 분류 항목을 기재합니다.
  - 글머리기호, 기본폰트크기, Bold 처리, 상태 표기 없음
  - 주요 대분류 항목 (예시)
        - 전략 / 한컴어시스턴트 / 한컴피디아 / 한컴데이터로더
        - AI / SDK / Add-Ons / 오피스 / 웹한글 / 기타 등
- 2단계 (소분류): 하위 들여쓰기 후, 실제 단위 업무명을 기재하며, 업무카드 텍스트에 하이퍼링크 추가
  - 하위 들여쓰기, 글머리기호, 기본폰트크기, 하이퍼링크
  - 형식: [상태] 업무 제목 (목표일/완료일, 상태
- 3단계 (상세내용): 하위 들여쓰기 후, 진행된 세부 내역이나 이슈와 일자, 상태를 작성합니다.
  - 하위 들여쓰기, 글머리기호, 기본폰트크기, (목표일/완료일, 상태)

### 2.2. 업무 상태 구분
소분류 앞머리의 [ ] 안에 아래 3가지 중 하나를 표기합니다.
- [예정]: 시작 전 업무
- [진행]: 현재 진행 중인 업무
- [완료]: 이번 주에 완료된 업무
